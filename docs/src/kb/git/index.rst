Git and GitHub
==============

Git is a distributed version control system. It tracks changes to files locally
and helps you share history between remotes. GitHub is a hosting and collaboration
platform built on top of Git repositories, with pull requests, issues, and related
workflow tools. Use the articles listed below for how-tos on this cluster; the
Resources section has short videos that introduce the core ideas.
